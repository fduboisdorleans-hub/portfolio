# Portfolio – Franck DUBOIS--DORLEANS

Portfolio BTS SIO option SISR : présentation, compétences, projets, parcours, veille technologique et contact.

Site statique en **HTML / CSS / JavaScript**, sans dépendance. Pour le voir : ouvrir `index.html` dans un navigateur, ou activer **GitHub Pages** (Settings → Pages → branche `main`, dossier `/`).

## Structure
- `index.html` – accueil et à propos
- `competences.html` – compétences techniques, référentiel BTS, langues, savoir-être
- `projets.html` – projets (générés depuis le tableau `projets` dans `script.js`)
- `parcours.html` – expériences, formation, certifications
- `veille.html` – veille technologique
- `contact.html` – coordonnées et formulaire
- `style.css` – thème « Bassin »
- `script.js` – menu, filtres, fenêtre de détail, animations, formulaire
